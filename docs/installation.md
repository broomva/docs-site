# Installation

Pocket Timer installs with pipx on macOS, Linux and Windows. The steps are the same on all three.

## macOS

Run this command in Terminal:

```
pipx install pocket-timer
```

## Linux

Run this command in your terminal:

```
pipx install pocket-timer
```

## Windows

Run this command in PowerShell or Command Prompt:

```
pipx install pocket-timer
```

You need pipx installed first. If you do not have it yet, install it before you run the command above.

## Check the install

Run `pocket --version` to confirm that Pocket Timer is installed. The command prints the version number.

When the check works, continue with [Getting started](getting-started.md) to run your first session.
