# Installation

Pocket Timer installs with pipx on macOS, Linux and Windows. You need Python 3 and pipx first.
If pipx is not installed yet, install it with your system's package manager or Python tooling.

## macOS

Install pipx, then install Pocket Timer:

```
pipx install pocket-timer
```

## Linux

Install pipx with your distribution's package manager, then install Pocket Timer:

```
pipx install pocket-timer
```

## Windows

Install pipx from your Python installation, open a new terminal, then install Pocket Timer:

```
pipx install pocket-timer
```

## Check the install

Run `pocket --version` to see the installed version. If the command is not found, close the terminal
and open a new one, so that pipx's install folder is on your `PATH`.

When the version prints, you are ready for [your first session](getting-started.md#your-first-session).
